- Estudiante: Joseph Castro
- Asignatura: Algoritmos y Lógica de Programación
- Variante: A (promedio mínimo de aprobación: 11)

## Problema
Sistema de consola para registrar, consultar, procesar y guardar las calificaciones de los estudiantes de una asignatura.

## Compilación y ejecución
Desde la carpeta principal del proyecto (la ruta de datos es relativa):

    javac -d out src/*.java
    java -cp out Main

## Funcionalidades
- Registro con validaciones.
- Listado y búsqueda por código.
- Reporte académico con orden por promedio.
- Guardado y recuperación en datos/estudiantes.txt.

## Limitaciones
- No permite editar ni eliminar estudiantes.
- Si el archivo tiene una línea dañada, se avisa y no se guarda, para no perder datos.

## Uso de IA
Se utilizó IA como apoyo en el desarrollo, con autorización del docente.
